# 棉花糖实验室 Marshmallow Lab

## 1. 演示脚本

1. 开场：PC 打开首页，右上角二维码投屏，请评委扫码。
2. 第二幕末：全场玩模块 1 回合 1（60 秒裸考），大屏展示等待数据。
3. 第三幕开场：切到模块 3 数据柱状图：「看，我们自己的网站上，可信组与不可信组的差距，和论文一模一样」。
4. 结尾：回放榜单 + 请评委生成结果卡分享。

主持人口播：「这就是我们论点的证据工厂——在座各位就是被试。」

演示前请核对本机结果。第 3 步是建设指令指定的演示台词，本网站的数据不能预先保证复现论文差异。每台设备独立保存数据，评委手机上的记录不会同步到投影电脑。只有实际数据支持时才可声称出现相同方向的差异。

## 2. 数据说明

全部数据仅存访客本机。模块 3 为互动复刻实验，虚拟奖励、事后完整解释。网站的虚拟糖果币没有现实价值。当前实现无需后端、注册或构建，也不会向外部发送实验记录。

五个存储键固定为 mlab_v1、mlab_v2、mlab_v3、mlab_board、mlab_nick。所有读写均有异常捕获，隐私模式或本地存储不可用时退回内存，跨刷新丢失可接受。关闭挑战会保留零秒放弃记录，重新进入时允许从该回合开头继续。

如需跨设备实时统计可接 Supabase/Firebase，本期不实现。

## 3. 实现备注

- 项目是六个 UTF-8 无 BOM 文件。双击 index.html 即可运行。发布时只上传本目录的六个文件，vendor 中两个脚本已本地化，不在运行时请求 CDN。
- 原有工作区包含其他项目，本网站放在独立 marshmallow-lab 目录。该目录本身就是要上传 GitHub Pages 的仓库根目录。
- 视觉遵循指定奶油色、粗描边、贴纸卡片及系统字体。角色为本项目原创内联 SVG。尊重系统减少动态效果设置。
- 模块 1 开始回合时先持久化 giveup:true、waitSec:0。主动放弃或关页后从同一回合重试，重试覆盖这一条标记，不发放保底，也不加入完成者分布。只有完整完成三回合才进入百分位。
- mlab_v1.rounds 按顺序保留本机历次三回合记录，round 为 1/2/3；重试的放弃标记原位替换。totalCoins 是已完成回合的累计糖果币，结算单独计算本次三回合总和。mlab_board.totalSprintSec 仅保存每次三回合等待总秒数，totalWaiters 为该数组长度。榜单据真实完整三回合记录计算总糖果币和最长单回合等待，按糖果币优先、最长等待次之排序。昵称始终为当前浏览器的本地昵称。
- 排名百分比采用严格小于当前成绩的本机完成记录数量除以本机记录总数，含当前记录；相同成绩不算被超过。结果卡依模块使用三回合等待总秒数、人生储蓄年数、信任挑战等待秒数排名，均注明本机比较范围。
- 回合 2 选卡即开局；执行意图卡需先选择计划。藏起来卡完全遮住并禁用诱惑按钮，但仍可主动放弃回合。泡泡可重复点按。换个想法卡仅改变诱惑呈现。执行意图卡每 15 秒发起一轮完整 4 秒吸气、7 秒屏息、8 秒呼气引导，重叠时并列显示，直到本局结束。
- 模块 1 每 8 秒换诱惑文案，每过 20 秒按钮放大 4%，最后 10 秒显示鼓励。倒计时以 Date.now() 时间差校正，回到前台会立即结算到期成功。
- 指令同时要求“1 秒 = 1 年、30 秒”及“每年选择窗口 4 秒”。本实现每年最少 1 秒，已选择则满 1 秒推进；未选择可等满 4 秒并默认存起来。因此主动快速操作约 30 秒，全部不操作约 120 秒。每年完整选择后再累计到曲线。
- 复利公式按月末投入 450、月利率 0.07/12 计算。选择储蓄的一年投入 12 期，奶茶年只滚动既有余额。全存 n 年公式为 450×(((1+0.07/12)^(12n)−1)/(0.07/12))，显示四舍五入到百位。按该公式 10/20/30 年分别约 77,900 / 234,400 / 549,000，与指令指定的 78,000 / 230,000 / 550,000 不完全一致。固定文案原样保留，曲线使用公式结果并说明差异。奶茶累计按每天 15×365×年数计算，30 年为 164,250，固定对照保留约 164,000。
- 模块 3 每次开始抛硬币随机分组，刷新后下一次开始作为新样本。小任务超时允许重试，未完成记录保留 taskDone:false 和 waitSec:0。小任务点中糖果后重新随机位置。可信组小任务奖励兑现 50；不可信组显示指定失败信息，不发放该奖励；挑战忍满兑现 100，提前点击兑现保底 60。
- 离开进行中的信任实验会结束本次实验、记零秒并先显示完整解释。解释阅读后可继续导航，保证不会留下未解释的失信体验。挑战分组提示在实验结束时揭示。
- 信任实验图中灰色参考线为论文 181.57 / 722.43 秒，图轴上限 800 秒。本机挑战上限 60 秒，与论文原始任务的 900 秒不同，页面明确标注，不能直接比较为同一实验。总样本不足 2 时不画本机柱；缺失的组用 null，不伪造为零。
- 建设指令允许表情白名单与其固定彩蛋和分组信息中的 🎉、✅、⚠️ 有冲突，固定原文优先，仅在指定位置保留。
- 引文、学术数字和固定文案按建设指令保留。来源页仅将原文 URL 转为可在新标签页打开的链接。流程中的引文保留 URL 文本，不设置外链，以免打断游戏。
- 首页二维码及结果卡二维码取当前页面地址。公开部署后它们指向真实部署网址；本地 file 地址与 127.0.0.1 地址仅用于本机体验，不支持评委其他手机扫码访问。PNG 由 Canvas 绘制为 750×1334，手机可长按保存，也提供下载。
- 2026-11-24 已通过 Sites 发布 HTTPS 网址：https://marshmallow-lab-pbl.gpt-shared-qy.chatgpt.site 。已于 2026-11-24 经用户明确授权开启公开访问。实际手机与匿名访问触发 Cloudflare 403，当前地址暂不能作为评委扫码入口。GitHub 账号已授权，公开仓库为 https://github.com/Alex-lushan/marshmallow-lab ，正在发布到 GitHub Pages。托管工作目录为 output/sites/marshmallow-lab，发布静态目录为 dist，托管配置保存在 .openai/hosting.json。
