# 棉花糖實驗室 Marshmallow Lab

正式網址：https://alex-lushan.github.io/marshmallow-lab/
公開倉庫：https://github.com/Alex-lushan/marshmallow-lab

## 1. 演示腳本

1. 用電腦開主頁投影，請評委掃右上角嘅二維碼。
2. 玩棉花糖挑戰，三個回合分別等 20、25、30 秒。即刻享受拎 2 粒，等足就拎 5 粒。
3. 玩信任實驗，完成小任務後進入 25 秒挑戰，再一齊睇返實驗解說同本機數據。
4. 睇排行榜，請評委整張成績卡，儲存或分享。

本機數據唔會同其他裝置同步。演示時只按實際結果解讀，唔預先保證兩組會重現論文差異。

## 2. 數據說明

所有成績只儲喺訪客自己嘅瀏覽器。信任實驗係互動重演，獎勵全部係虛擬棉花糖，實驗做完會完整解說。

沿用 mlab_v1、mlab_v2、mlab_v3、mlab_board、mlab_nick 五個存儲鍵。讀寫都有異常處理，儲存不可用時改用記憶體，遊戲仍然玩得完。

2026-11-25 新玩法記錄帶有 rulesVersion:2。舊版記錄保留原來嘅等待秒數，唔會改成新成績。新挑戰嘅排行榜、百分位、人生模擬比較同信任實驗圖只用新版記錄。totalCoins、coinsSpent、coinsSaved 沿用欄位名，以兼容舊資料，今版意思係棉花糖數量。

如需跨裝置統計，可另接後端；今期維持純靜態同本機儲存。

## 3. 實現備註

- 六個檔案為 index.html、styles.css、app.js、vendor/chart.umd.min.js、vendor/qrcode.min.js、README.md。唔使安裝依賴或建置，雙擊 index.html 就玩得。
- 最新用戶要求優先。頁面採用繁體粵語，HTML 語言標記為 yue-Hant-HK。英文書目、作者、年份、DOI、論文數字同原文連結保留；中文解說改成粵語。
- 即時獎勵統一 2 粒棉花糖，延遲獎勵統一 5 粒，比例係 2.5 倍。三個回合分別等 20、25、30 秒，信任實驗挑戰等 25 秒。結算、總數、圖表、排行榜同 PNG 成績卡共用同一套規則。
- 棉花糖圖案直接重用原創 SVG。即時按鈕顯示 2 粒，延遲獎勵區顯示 5 粒，小任務亦改為棉花糖。
- 三回合全成功可累積 15 粒；呢個係三次獎勵嘅合計。每一次獎勵仍然係即時 2 粒或延遲 5 粒。
- 信任實驗小任務成功嘅承諾獎勵係 2 粒。可信組會兌現；唔可信組按既有實驗設計暫不兌現，之後完整解說。挑戰本身仍按即時 2 粒／等足 25 秒 5 粒結算，總數分開相加。
- 等待用 Date.now() 時間戳差計算，返前台會校正。判斷成功用未四捨五入嘅時間，唔會提早派延遲獎勵。
- 開局先寫入零秒放棄記錄，重開頁面可由同一回合開始；重試只替換同版玩法嘅放棄記錄。
- 四種策略維持原有功能。收埋佢遮住並停用即時按鈕；轉移注意力可以撳泡泡；換個諗法將誘惑畫成雲；如果—就咁做於開局第 1 秒開始一輪完整 4-7-8 呼吸引導，配合縮短咗嘅回合時長。
- 兩種人生保留 30 年模擬。每年即刻享受食 2 粒，延遲享受累積 5 粒；作為數學教學假設，之前累積嘅數量每年增長 7%。公式係 balance×1.07+5（選擇延遲時），全儲 n 年為 5×((1.07^n−1)/0.07)。顯示保留最多一位小數，屬虛擬模型。每年最少 1 秒，未選則 4 秒後預設延遲；主動操作約 30 秒，全不操作約 120 秒。
- 舊版「每日 15 糖果幣」嘅財務對照已隨獎勵單位修改而換成上述棉花糖模型。
- 信任圖保留論文對照線 181.57 秒與 722.43 秒，清楚標示本遊戲上限 25 秒、論文任務上限 900 秒。缺少嘅組別用 null，唔會假裝有零秒樣本。
- 二維碼直接取頁面網址。現有 GitHub 版二維碼仍然指向同一網址。成績卡由 Canvas 生成 750×1334 PNG，所有可見文案同樣係粵語。
- 本次更新為 CSS 同應用腳本加上版本參數，方便已玩過嘅瀏覽器載入新文案同規則。
- 正式發布位置係 GitHub Pages main / root。早期 chatgpt.site 地址曾遇到 Cloudflare 403，評委入口使用上方 GitHub Pages 網址。
